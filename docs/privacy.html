隐私政策

最后更新：2026年7月20日

嗅密（以下简称"本应用"）是一款 macOS 平台上的本地密码管理工具。我们高度重视您的隐私。本隐私政策旨在向您说明：本应用不收集、不使用、不分享您的任何个人数据。

1. 数据收集

本应用不会收集任何数据。具体而言：

  • 不收集任何个人身份信息
  • 不收集任何设备信息
  • 不收集任何使用统计数据
  • 不包含任何第三方分析或追踪 SDK
  • 不发起任何网络请求

您创建的所有密码数据均仅存储在您的本地设备上（具体路径：~/Library/Application Support/嗅密/），采用行业标准加密算法保护。

2. 数据存储与加密

所有密码数据使用 CryptoKit 加密后存储在本地文件系统中，加密密钥由 macOS 系统钥匙串（Keychain）安全保管。任何第三方均无法访问这些数据。

3. 数据共享

由于本应用不从您的设备收集任何数据，因此不存在与第三方共享数据的情况。

4. 您的权利

您可以随时：

  • 查看、编辑或删除存储的任何密码数据
  • 通过删除应用来彻底清除所有数据

数据完全归您所有和控制。
